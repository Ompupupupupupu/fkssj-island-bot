【fkssj 海岛经营游戏自动化】
├─ 单次操作(直接说需求即可)
│  ├─ 检查贸易: 三艘贸易船状态检查 + 自动交货
│  ├─ 检查资源: 7 种资源剩余数量 OCR 检查(只读)
│  ├─ 采集资源: 时长按剩余百分比自动定 1/3/5 分钟
│  ├─ 领取在线奖励: 手动领取第 1-7 次中任一次城战在线奖励
│  ├─ 自动闯关: 后台连续打关卡, 说"停止闯关"即停, 结束后战果自动推送
│  ├─ 回主界面: 主界面检查与自动恢复 / 强制恢复
│  ├─ 启动游戏 / 停止游戏
│  ├─ 检查游戏状态: 只读探测模拟器与游戏是否在运行
│  ├─ 暂停自动化: 说"暂停自动化/我想自己玩一会"一键暂停定时任务/提醒/监视/闯关(满1小时未恢复主动询问一次)
│  ├─ 恢复自动化: 恢复暂停前开启的服务(闯关除外)
│  └─ 模拟器配置检查修正(平板版 1920x1080 + DPI 280)
├─ 定时任务(说"开启/关闭 + 任务名")
│  ├─ 自动检查贸易: 默认每 30 分钟检查并交货(可指定周期), 异常才推送, 正常轮静默(没消息=一切正常)
│  ├─ 自动检查资源: 默认每 30 分钟检查资源, 不足时按组采集(可指定周期), 有采集或异常才推送
│  ├─ 自动领取城战在线奖励: 每天 20:25 起自动领完 7 次(后台完成, 奖励 20:00-21:00 可领)
│  ├─ 夜间总结推送: 每天 08:04 把夜间日志统一总结推送一次
│  └─ 每日服务总结: 每天 01:04 盘点开了哪些服务与各服务当天完成次数并推送
├─ 提醒与监视(说"开启/关闭 + 名称", 脚本直推不经对话, 不消耗 token)
│  ├─ 货轮提醒: 每天 8:00-22:00 每个整点推送提醒
│  ├─ 商船提醒: 每天 8/11/14/17/20/23 点推送提醒
│  ├─ 提醒停用清单: 随时停用/恢复某一提醒(往 fkssj_reminder_off 写/删提醒名, 见 chat.md)
│  └─ 私聊监视: 后台常驻每 2 分钟检测未读私聊, 发现即推送提醒(说"停止私聊监视"即停)
└─ 规则说明
   ├─ 夜间规则: 01:00:00-07:59:59 定时任务只执行不推送, 结果记入夜间日志, 早上由夜间总结推送统一推送; 唯一例外是 01:04 每日服务总结照常推送; 遇游戏未运行不询问直接跳过本轮
   ├─ 长跑自推: 闯关/领取序列结束后战果自动推送(夜间同样记入夜间日志)
   ├─ 启动确认: 游戏未运行时定时任务会先询问是否启动游戏(3分钟内未回复视为不同意)
   └─ 推送可达性: 长时间未与 bot 对话后, 微信可能收不到定时任务与提醒的推送(任务本身照常执行不耽误); 给 bot 发任意一条消息即可恢复推送, 漏掉的结果可在桌面端会话或每日总结查看
