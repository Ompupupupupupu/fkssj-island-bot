# fkssj-island-bot

海岛经营游戏（fkssj）自动化 Hermes skill：通过雷电模拟器的 adb 驱动游戏，
提供贸易船管理、资源采集、自动闯关等单次执行的自动化脚本，并支持用 /cron 编排定时任务。

## 功能特性

- **模拟器配置检查/修正**：自动校验并修复雷电模拟器平板版预设（分辨率 1920×1080、DPI 280）
- **启动/停止游戏**：冷启动并等待停到主界面
- **主界面检查与自动恢复**：四重判定（模板匹配 + 像素颜色 + OCR），异常时层层退回，
  常规恢复失败可强制重启游戏恢复
- **贸易船检查 + 自动交货**：三船状态识别（未回来/已回来/货物不全），已回来自动收货结算交货
- **资源检查**：7 种资源 OCR 读数，低于上限 70% 标记不足
- **资源采集**：按剩余百分比自动定采集时长（1/3/5 分钟），支持多资源分组编排
- **自动闯关**：长跑循环，胜利自动下一关，连败/超时自动告警退出并恢复主界面
- **定时任务（/cron）**：自动检查贸易/资源（夜间 01:00-08:00 只执行不推送，资源不足自动采集）、
  搁浅货轮整点提醒、联盟商船定点提醒

设计原则：**单次执行、检查与操作分离、结果可解析**——每个脚本跑一轮就退出，
输出机器可解析的 `RESULT:` 汇总行与语义化 exit code（0 成功 / 1 失败 / 2 需用户行动）。

## 环境要求

- Windows + 雷电模拟器 9（平板版预设：配置分辨率 1920×1080、DPI 280；
  竖屏显示下 adb 截图为 1080×1920，全部坐标基于此）
- Python 3.12+（已装 requirements.txt 依赖；实测 3.11 与 rapidocr-onnxruntime 不兼容）
- 仅支持单模拟器实例（emulator-5554 / 实例 leidian0）

## 安装部署

1. 将本 skill 目录放入 Hermes 的 skills 目录（如 `skills/automation/`）：

```text
skills/automation/fkssj-island-bot/
```

2. 安装 Python 依赖：

```text
pip install -r requirements.txt
```

3. 确认模拟器配置（非默认安装位置加 `--ld-dir`，多实例加 `--instance`）：

```text
python scripts/setup_emulator.py
```

4. 首次部署或游戏改版后，按 SKILL.md"维护与校准"节实测校准判定。

## 脚本清单

| 脚本 | 功能 | exit code |
|---|---|---|
| scripts/setup_emulator.py | 检查并修正模拟器基础配置 | 0/1/2 |
| scripts/start_game.py | 启动游戏（已运行则只报告状态） | 0/1 |
| scripts/stop_game.py | 停止游戏 | 0/1 |
| scripts/check_main.py | 检查并自动恢复主界面 | 0/1 |
| scripts/check_ships.py | 贸易船检查 + 自动交货 | 0/1/2 |
| scripts/check_res.py | 7 种资源 OCR 检查（只读） | 0/1/2 |
| scripts/gather_res.py | 采集一种资源（时长自动判定） | 0/1 |
| scripts/force_main.py | 强制回主界面（重启游戏兜底） | 0/1 |
| scripts/battle_run.py | 自动闯关长跑（Ctrl+C 中断） | 0/1 |

详细用法、输出规范、恢复链与分组编排规则见 [SKILL.md](SKILL.md)。

## 定时任务

配合 Hermes `/cron` 可编排 4 类定时任务（详见 SKILL.md"定时任务与提醒"节）：

| 任务 | 默认周期 |
|---|---|
| 自动检查贸易 | `*/30 * * * *`（周期可指定） |
| 自动检查资源 | `*/30 * * * *`（不足自动采集；周期可指定） |
| 搁浅的货轮提醒 | `0 8-22 * * *`（每天 8-22 点整点） |
| 联盟商船提醒 | `0 8,11,14,17,20,23 * * *` |

夜间 01:00-08:00 只执行检查、不向用户推送。

## 注意事项

- 脚本通过本机 adb server（127.0.0.1:5037，随雷电模拟器自动运行）直连设备，无需 adb 在 PATH。
- 运行时截图写入 `%TEMP%/fkssj_skill_shots/`。
- 所有脚本串行执行（共享同一台设备）；`battle_run.py` 与其余脚本互斥。
