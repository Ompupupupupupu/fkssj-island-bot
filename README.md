# fkssj-island-bot

海岛经营游戏（fkssj）自动化 Hermes skill：通过雷电模拟器的 adb 驱动游戏，
提供贸易船管理、资源采集、自动闯关等单次执行的自动化脚本，支持用 /cron 编排定时任务，
并提供货轮/商船到点提醒、私聊未读监视、长跑战果自动推送等不经对话的直推设施。

## 功能特性

- **模拟器配置检查/修正**：自动校验并修复雷电模拟器平板版预设（分辨率 1920×1080、DPI 280）
- **启动/停止游戏**：冷启动并等待停到主界面
- **主界面检查与自动恢复**：四重判定（模板匹配 + 像素颜色 + OCR），异常时层层退回，
  常规恢复失败可强制重启游戏恢复
- **贸易船检查 + 自动交货**：三船状态识别（未回来/已回来/货物不全），已回来自动收货结算交货
- **资源检查**：7 种资源 OCR 读数，低于上限 70% 标记不足
- **资源采集**：按剩余百分比自动定采集时长（1/3/5 分钟），支持多资源分组编排
- **自动闯关**：后台长跑，胜利自动下一关，连败/超时自动告警退出并恢复主界面，结束后战果自动推送（夜间记入夜间日志）
- **城战在线奖励领取**：手动领取第 1-7 次中任一次，或定时后台序列领完 7 次，结束后结果自动推送
- **经验领取**：统一领取训练营/冶炼厂/海兽训练营等各建筑累积经验（单次，或每 8 小时与联盟情报合并定时领取）
- **联盟情报领取**：联盟情报界面一键领取累积情报，循环领完为止，等级提升特别标注（单次，或每 8 小时与经验合并定时领取）
- **闯关挂机奖励领取**：进闯关奖励界面先清升级点，按挂机小时与上限判断（≥上限-1 或 ≥23 保底），未达条件不领取静默退出（单次，或随贸易任务每 30 分钟顺路领取）
- **定时任务（/cron）**：自动检查贸易（顺路领取闯关挂机奖励）/资源（夜间 01:00:00-07:59:59 只执行不推送、
  结果记入夜间日志，资源不足自动采集；日间异常才推送——一切正常不汇报，
  有采集/交货失败/异常才推送，没消息=一切正常）、自动领取城战在线奖励、
  自动领取经验与联盟情报（每 8 小时合并领取，经验领取成功才推送；
  情报领取完成静默，等级提升或无情报可领才推送）、
  夜间总结推送
  （每天 08:04 把夜间日志统一总结推送一次）、每日服务总结（每天 01:04 盘点当前
  开启的服务与各服务当日完成次数并推送，夜间照常直推）；
  定时任务遇游戏未运行会先询问用户是否启动（3 分钟无回复跳过本轮）
- **推送设施（非 /cron，脚本直推不经对话）**：闯关/领取序列结束后战果自动推送；
  搁浅货轮整点提醒与联盟商船定点提醒由 Windows 计划任务到点唤醒脚本直推；
  私聊未读监视常驻后台每 2 分钟检测、发现未读即推送（脚本直推内置 30 秒推送锁）
- **一键暂停/恢复自动化**：说"暂停自动化 / 我想自己玩一会"即停掉全部定时任务、
  货轮/商船提醒、私聊监视与后台长跑（满 1 小时未恢复由一次性询问任务
  repeat=1 主动询问一次）；说"恢复自动化"按暂停前状态逐项恢复（闯关不自动恢复）

设计原则：**单次执行、检查与操作分离、结果可解析**——每个脚本跑一轮就退出，
输出机器可解析的 `RESULT:` 汇总行与语义化 exit code（0 成功 / 1 失败 / 2 需用户行动，含设备被占用——任务脚本启动自检发现其他占设备脚本在跑时不执行直接退出）。

## 环境要求

- Windows + 雷电模拟器 9（平板版预设：配置分辨率 1920×1080、DPI 280；
  竖屏显示下 adb 截图为 1080×1920，全部坐标基于此）
- Python 3.12+（已装 requirements.txt 依赖；实测 3.11 与 rapidocr-onnxruntime 不兼容）
- 仅支持单模拟器实例（emulator-5554 / 第一个实例，实例目录 leidian0）

## 安装部署

1. 将本 skill 目录放入 Hermes 的 skills 目录（如 `skills/automation/`）：

```text
skills/automation/fkssj-island-bot/
```

2. 安装 Python 依赖：

```text
pip install -r requirements.txt
```

3. 确认模拟器配置（非默认安装位置加 `--ld-dir`，多实例加 `--instance`）：

```text
python scripts/setup_emulator.py
```

4. 首次部署或游戏改版后，按 [references/maintenance.md](references/maintenance.md)
   的校准流程实测校准判定。
5. 重新打开 Hermes 会话——skill 加载器在会话启动时缓存列表，新装或更新的 skill
   需要新会话才会生效。

> 本机完整路径命令清单（`local/commands.md`）为机器私有部署工件，已被 `.gitignore`
> 排除、不随仓库分发；该文件不存在时，按 SKILL.md"运行位置"节的通用模板
> （`<PYTHON> <SKILL_DIR>/scripts/<脚本名>.py`）以实际安装路径执行即可。

## 定时任务与推送设施

配合 Hermes `/cron` 可编排 6 类定时任务（详见 [references/cron.md](references/cron.md)）：

| 任务 | 默认周期 |
|---|---|
| 自动检查贸易 | `*/30 * * * *`（周期可指定，顺路领取闯关挂机奖励） |
| 自动检查资源 | `5,35 * * * *`（不足自动采集；周期可指定） |
| 自动领取城战在线奖励 | `25 20 * * *`（每天 20:25 唤醒，后台序列领完 7 次；奖励仅 20:00-21:00 可领） |
| 自动领取经验与联盟情报 | `50 0,8,16 * * *`（每 8 小时合并领取：各建筑经验领取成功才推送；联盟情报领取完成静默，等级提升或无可领才推送） |
| 夜间总结推送 | `4 8 * * *`（每天 08:04 把夜间日志统一总结推送一次并清空） |
| 每日服务总结 | `4 1 * * *`（每天 01:04 盘点开启服务与各服务当日完成次数并推送；夜间照常直推） |

对 Hermes 说"开启/关闭 + 任务名"（如"开启自动检查贸易"）即可管理，检查类任务的
检查周期可自定义（如"每 1 小时检查一次贸易"）；全部触发词与 prompt 模板见
[references/cron.md](references/cron.md)。

全部定时任务的执行摘要都记录在本地日志，可自行查看：夜间日志 `$TEMP/fkssj_night_events.log`
（夜间窗口 01:00:00-07:59:59 各轮结果，每天 08:04 总结推送后清空）、每日统计
`$TEMP/fkssj_stats.log`（各服务当日完成计数，每天 01:04 总结后清空）；$TEMP 即系统
临时目录，Windows 资源管理器地址栏输入 `%TEMP%` 可直达。

另有不经 /cron 的推送设施（详见 [references/chat.md](references/chat.md)）：

| 设施 | 触发方式 |
|---|---|
| 搁浅的货轮提醒 | Windows 计划任务每天 8-22 点整点唤醒脚本直推 |
| 联盟商船提醒 | Windows 计划任务每天 8/11/14/17/20/23 点唤醒脚本直推 |
| 私聊未读监视 | chat_watch.py 后台常驻，每 2 分钟检测，发现未读直推（--stop 停止） |

货轮/商船提醒可随时单独停用/恢复：往 `$TEMP/fkssj_reminder_off` 一行写停用的
提醒名（`cargo` / `ship`，空格或逗号分隔，两类都写即全停；缺省或清空 = 都推），
不影响计划任务注册（详见 [references/chat.md](references/chat.md)）。

另支持一键暂停/恢复全部自动化：说"暂停自动化""我想自己玩一会""恢复自动化"
即可——暂停会删除当时全部定时任务、静默提醒、停止私聊监视与后台长跑并记录
状态文件，恢复按暂停前清单逐项重建（闯关除外）；暂停满 1 小时未恢复由一次性
询问任务（repeat=1，跑完自动收尾）主动询问一次（详见
[references/pause.md](references/pause.md)）。

闯关/城战领取序列（长跑）结束后由脚本退出路径自动推送战果，无需定时任务参与。

夜间 01:00:00-07:59:59 定时任务只执行检查、不向用户推送，结果一律记入夜间日志
`$TEMP/fkssj_night_events.log`，早上由夜间总结推送任务统一总结推送后清空。
两个例外：每天 01:04 的每日服务总结照常直接推送；【fkssj 暂停询问】任务昼夜
照常询问（暂停中的用户大概率在手动游玩、未入睡，详见
[references/pause.md](references/pause.md)）。

## 注意事项

- 脚本通过本机 adb server（127.0.0.1:5037，随雷电模拟器自动运行）直连设备，无需 adb 在 PATH。
- 运行时截图写入 `$TEMP/fkssj_skill_shots/`。
- 所有脚本串行执行（共享同一台设备）；任务脚本启动前自检设备占用，发现其他占设备
  脚本在跑则不执行、exit 2（不打扰执行中的任务）；`battle_run.py` 与其他任务冲突时其他任务优先
  （先 `--stop` 停止闯关并汇报战果，再执行该任务，详见 [references/battle.md](references/battle.md)）；
  `claim_seq.py` 与其余脚本互斥（检查类定时任务遇其在跑则跳过本轮，
  详见 [references/reward.md](references/reward.md)）；`chat_watch.py` 常驻监视
  遇闯关/领取序列在跑时让位跳过该轮（详见 [references/chat.md](references/chat.md)）。
